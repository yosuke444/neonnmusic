# 50曲の全体計画（spec.md 10-6 手順1）

- 1〜10曲目は最初から解禁される曲。ジャンルとBPMを広く散らし、イージーが遊びやすい曲にする。
- 曲名は1〜10曲目のみ決定済み。11曲目以降は各回で決める（計画のジャンル・BPM・キーは各回で微調整することがある）。
- チップチューンは2曲（20・34）。複合ジャンルは12曲（約2割）。
- 試作曲3曲（サウンドテスト専用）は50曲に含めない。

## 構成の長さ（BPMによる）
設計書の基本形（イントロ8＋ビルド8＋ドロップ16＋ブレイク8＋ビルド8＋ドロップ2 16＋アウトロ8＝72小節）は、
BPM115未満では2分30秒を超える。そのため次の形を使い分ける。

| 形 | 小節数 | 使うBPM | 内容 |
|---|---|---|---|
| 基本形 | 72 | 116〜169 | 8・8・16・8・8・16・8 |
| 中くらい | 64 | 104〜115 | 2回目のビルドとアウトロを4小節に |
| 短い形 | 52 | 103以下 | ビルド・2回目のビルド・アウトロを4小節、ドロップ2を8小節に |
| 長い形 | 88 | 170以上 | イントロとブレイクを16小節に（1分30秒を下回らないように） |
